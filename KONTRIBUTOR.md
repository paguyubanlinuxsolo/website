# Panduan Kontributor — Menulis di linuxsolo.or.id

Halo, terima kasih sudah mau nulis untuk Paguyuban Linux Solo! 🐧
Nulis di sini **tidak perlu coding** — semua lewat dashboard online.

## 1. Sekali saja: aktivasi akses

1. Cek email / notifikasi GitHub kamu — ada undangan (invite) ke repo
   `paguyubanlinuxsolo/website`. Klik **Accept invitation**.
2. Buka **https://linuxsolo.or.id/admin/** lalu klik **Login with GitHub**
   dan izinkan aksesnya. Kalau dashboard-nya muncul, kamu siap.

## 2. Buat profil penulis kamu (sekali saja)

Supaya tulisanmu tampil dengan nama & fotomu:

1. Di sidebar kiri pilih **Penulis** → **New Penulis**.
2. Isi **Nama** (nama pena kamu — ini yang tampil di artikel), foto,
   bio singkat, dan username GitHub/Telegram kalau mau.
3. Klik **Save**, lalu minta admin menerbitkannya (lihat alur review di bawah).

## 3. Menulis post

1. Sidebar kiri → **Post** → **New Post**.
2. Isi field-nya:

   | Field | Catatan |
   |---|---|
   | **Judul** | Judul artikel. |
   | **Slug (URL)** | Alamat artikel, mis. `kopdar-oktober-2026` → tampil di `linuxsolo.or.id/kopdar-oktober-2026/`. Hanya huruf kecil, angka, dan tanda minus — tanpa spasi atau garis miring. |
   | **Tanggal terbit** | Biarkan default (sekarang) atau sesuaikan. |
   | **Penulis** | Pilih nama kamu dari daftar (profil yang dibuat di langkah 2). |
   | **Deskripsi singkat** | 1–2 kalimat ringkasan — dipakai untuk SEO & kartu di halaman blog. Isi ya, jangan dikosongi. |
   | **Gambar utama** | Foto/ilustrasi pembuka artikel. |
   | **Kategori** | `Artikel` (tulisan umum/tutorial), `Event` (liputan/pengumuman kegiatan), `Dokumentasi`. Boleh lebih dari satu. |
   | **Tag** | Kata kunci bebas, mis. `opensuse`, `kopdar`. Opsional. |
   | **Isi tulisan** | Badan artikel. Toolbar-nya mendukung heading, bold, link, kutipan, kode, dan sisip gambar (tombol **+** → Image). |

3. Klik **Save**. Tulisanmu tersimpan sebagai **Draft** — belum tampil di situs,
   dan kamu bisa lanjut mengedit kapan saja.

## 4. Alur terbit (editorial workflow)

Semua tulisan melewati tahap review sebelum tayang:

```
Draft  →  In Review  →  Ready  →  Terbit 🎉
(kamu)    (kamu ajukan)  (admin approve)
```

1. Kalau tulisanmu sudah siap, buka tab **Workflow** di menu atas,
   lalu geser kartu tulisanmu dari **Drafts** ke **In Review**
   (atau dari dalam editor: ubah **Set status** → *In review*).
2. Kabari admin (di grup Telegram) bahwa tulisanmu siap direview.
3. Admin mereview & meng-approve. Setelah itu tulisan bisa di-**Publish**
   dan tayang di situs sekitar 1–2 menit kemudian.

Catatan:

- Tombol **Publish** baru berhasil **setelah** admin approve — kalau kamu
  klik Publish dan muncul error, artinya reviewnya belum di-approve. Santai,
  itu bukan tulisanmu yang rusak.
- **Mengedit tulisan yang sudah terbit** juga masuk alur review lagi
  (revisi tersimpan sebagai draft baru sampai di-approve). Jadi jangan
  bingung kalau hasil edit tidak langsung tampil.

## 5. Tips gambar

- Ukuran wajar saja (± di bawah 1 MB per foto kalau bisa) — foto kamera
  langsung biasanya terlalu besar; kecilkan dulu biar situs tetap ngebut.
- Format `jpg`/`png`/`webp`.
